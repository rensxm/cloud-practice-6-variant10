# Файлдарды басқару

Файлдар туралы мәліметті PostgreSQL базасында сақтайтын веб-қосымша жасалды. Файлдар тізімін және жеке жазбаны қарау, жаңа файл туралы мәлімет қосу мүмкіндігі іске асырылды. Кіріс деректері тексеріледі, қате сұраныстар өңделеді. Базаға қосылу деректері орта айнымалыларында сақталады. Қосымша Render-де жарияланды.
